# 📖 What is Docker Logging?

Docker Logging is the process of collecting and managing output generated by containers.

Logs help developers and DevOps engineers:

* Debug Applications
* Identify Errors
* Monitor Performance
* Troubleshoot Failures

Containers write logs to:

* Standard Output (stdout)
* Standard Error (stderr)

---

# ❓ Why Logging and Monitoring Matter?

Imagine a production application crashes.

Without logs:

❌ No Error Information

❌ Difficult Troubleshooting

❌ Slow Recovery

With logs:

✅ Identify Issues Quickly

✅ Monitor Application Health

✅ Faster Incident Resolution

# 📜 Viewing Container Logs

View Logs:

```bash
docker logs container_id
```

Example:

```bash
docker logs nginx
```

---

### Follow Logs in Real-Time

```bash
docker logs -f container_id
```

Example:

```bash
docker logs -f nginx
```

---

### Show Last 50 Lines

```bash
docker logs --tail 50 container_id
```

---

### Show Timestamps

```bash
docker logs -t container_id
```

# 📦 Docker Log Drivers

Docker supports multiple logging drivers.

Check Current Driver:

```bash
docker info
```

Common Drivers:

| Driver    | Description              |
| --------- | ------------------------ |
| json-file | Default Docker Driver    |
| local     | Optimized Local Storage  |
| syslog    | Linux Syslog Integration |
| journald  | Systemd Journaling       |
| fluentd   | Fluentd Logging          |
| awslogs   | Amazon CloudWatch        |
| splunk    | Splunk Integration       |

---

---

# ⚙ Configure Log Driver

Example:

```bash
docker run \
--log-driver=json-file \
nginx
```

CloudWatch Example:

```bash
docker run \
--log-driver=awslogs \
nginx
```

# 🚨 Docker Events

Docker can stream real-time events.

View Events:

```bash
docker events
```

Example Events:

```text
container start
container stop
container die
network create
volume mount
```

Useful for monitoring container lifecycle.

# 🩺 Container Health Checks

Docker can automatically check application health.

Dockerfile Example:

```dockerfile
HEALTHCHECK CMD curl --fail http://localhost || exit 1
```

Health States:

```text
Healthy
Unhealthy
Starting
```

Inspect Health:

```bash
docker inspect container_id
```
